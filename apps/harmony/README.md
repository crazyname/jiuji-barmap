# HarmonyOS NEXT · React Native OpenHarmony

目标复用 `apps/mobile/` 中的 React Native 业务组件与 `packages/core/` 的 TypeScript 模型，通过 RNOH 接入鸿蒙原生项目，必要时以 ArkTS 封装地图、定位、相册、分享等 SDK。

参考：

- [React Native for OpenHarmony 示例](https://github.com/eclipse-oniro4openharmony/app-rnoh-example)
- [Expo Harmony 社区适配](https://github.com/renbaoshuo/expo-harmony)

当前为适配路线文档，尚未创建可直接打包的 HAP 工程；需要在 DevEco Studio 与实体设备上完成原生组件兼容性测试。
