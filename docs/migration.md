# 微信原生入口迁移至 uni-app x

原则：**先迁移、验证，再删除旧代码**。追踪表：[`migration-gates.json`](migration-gates.json)。使用 `npm run migration:status` 查看当前状态。

1. **基础契约（已完成）**：共享酒吧模型、API 草案、同步检查、平台能力矩阵与 Linux CI。
2. **页面对等**：uni-app x 微信端补齐地点详情、收藏、浏览历史、主题设置、酒吧新增、调酒教程、帖子编辑与商业推广标识。
3. **地图验收**：微信真机核查地图标记、缩放、选点、导航、坐标转换和各类权限。
4. **本机数据迁移**：验证收藏、配方、帖子从原生微信存储迁移到新客户端的方式（或明确要求用户导出/确认迁移）。
5. **双版本预览和回退**：开发版与体验版并行检查，确定可回退的稳定版本。
6. **切换入口**：上述门槛全部通过后，将 `project.config.json` 指向 uni-app x 输出，再移除 `miniprogram/` 及仅供旧项目使用的工具。

迁移前不要为了整理目录重命名 `miniprogram/`。这样可以让新开发者继续验证已有微信版本，也避免无意中丢失功能。
