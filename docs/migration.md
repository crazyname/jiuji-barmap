# 微信小程序迁移

目标：用 `apps/wechat/`（Taro + React + TypeScript）替换 `miniprogram/` 原生客户端。

1. **共享模型**：将 31 家酒吧数据同步至 React 两端（自动化检查）。
2. **四栏功能对等**：地图、调酒、社区、我的及其子页面。
3. **真实地图**：微信真机验证标记、搜索、定位与导航。
4. **本地记录**：验证原生微信收藏、配方、帖子和主题迁移。
5. **发布与回退**：体验版可正常使用，可快速恢复旧版本。
6. **切换**：通过上述验收后再切换微信项目入口，删除旧客户端。

`npm run migration:status` 查看验收状态。
