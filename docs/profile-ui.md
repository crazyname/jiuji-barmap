# 「我的」页面

微信 Taro 和 React Native 使用统一的 C「城市编辑」信息架构：

- 个人资料：昵称、简介均可编辑，当前先保存在设备本机。
- 我的内容：收藏、配方、探店分享；微信端同时提供浏览记录与清除功能。
- 数据同步：自动刷新公开数据，只展示“最近已更新”“离线可用”及待同步数量。
- 设置与隐私：账号、隐私说明与关于酒迹。

**普通用户页面不展示** API 地址、Sites / Cloudflare、设备令牌、数据库或其他开发设置。API 环境由客户端构建配置管理。

目前账号登录接口尚未实现，界面以访客模式呈现，不会模拟登录成功。现有本机资料正常保存；正式登录上线后，再将用户私人数据与同步队列关联到已验证的账号。服务端签发的用户会话由客户端认证层持有，不使用 Sites 管理员令牌。

测试令牌联调使用开发者测试工具/自动化测试，不放在正式的「我的」页面。
